# AI Face Recognition Attendance System

This project is an AI-based attendance system using Python, OpenCV, and machine learning.

## Features
- Face Detection using Haar Cascades
- Face Recognition using LBPH (Local Binary Patterns Histograms)
- Attendance Logging
- CSV and PDF Export
- Student Registration
- Analytics Dashboard

## Tech Stack
- Python
- OpenCV (with contrib modules)
- NumPy
- Pandas
- SQLite
- Gradio
- Plotly
- FPDF

## Deployment
- Compatible with Hugging Face Spaces CPU Basic
- No compilation required
- Lightweight memory usage
